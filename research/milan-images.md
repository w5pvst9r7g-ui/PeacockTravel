# Milan / Lake Como / Bergamo — Wikimedia Commons image research

Date: 2026-06-12. Method: Wikimedia hosts (commons.wikimedia.org, *.wikipedia.org, api.wikimedia.org) are
unreachable from this sandbox (curl egress-blocked, WebFetch 403), so all verification was done through
web-search snippets of Commons file/category pages. Direct URLs were built with the canonical MD5 scheme
(`md5sum` of the underscored filename, computed locally) and the scheme was sanity-checked against two
files whose canonical URLs are independently known (`a/a3` pizza, `4/4b` Última Cena).

Status legend:
- **VERIFIED** — file-page existence + license + author + dimensions all confirmed via search results.
- **PARTIAL** — file-page existence confirmed; one or more of license/author/dimensions unconfirmed.
  Manually open the Commons file page before shipping.

Attribution note: CC BY-SA requires author credit + license name/link; CC BY requires author credit;
CC0/public domain requires nothing (credit is still good practice). Dual GFDL/CC BY-SA files: just use
the CC BY-SA option. Hotlinking from upload.wikimedia.org is permitted by Wikimedia.

⚠ Thumb caveat: the `/thumb/...1280px-...` variant only exists when the original is wider than 1280px.
For the two originals ≤1024px wide an 800px thumb is given instead.
